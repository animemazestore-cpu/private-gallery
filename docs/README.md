# Private Gallery — Vibe Coding Project Docs

This folder contains the core Markdown context files for building a private, PIN-protected photo gallery with an admin upload system.

## Files

- `PROMPT.md` — master instruction for the coding AI; requires chunked implementation and persistent memory updates after every chunk.
- `PROJECT.md` — product requirements and scope.
- `ARCHITECTURE.md` — recommended technical architecture and data flow.
- `SECURITY.md` — security requirements and threat model.
- `DATABASE.md` — database/storage model.
- `UI_UX.md` — interface and responsive design requirements.
- `AUTH.md` — visitor PIN and admin authentication behavior.
- `ADMIN.md` — admin dashboard and media-management requirements.
- `API.md` — API contracts and server-side rules.
- `STORAGE.md` — photo storage, protected delivery, upload constraints, and lifecycle.
- `TESTING.md` — testing strategy and acceptance criteria.
- `DEPLOYMENT.md` — deployment/environment requirements.
- `MEMORY.md` — persistent implementation memory and current project state.
- `TASKS.md` — chunk-by-chunk implementation roadmap.
- `DECISIONS.md` — architecture/product decision log.
- `ENVIRONMENT.md` — environment variables and secrets policy.
- `CONTRIBUTING.md` — coding conventions for the AI/human workflow.

> Never put real secrets, PINs, service-role keys, or private photo URLs in these files.
