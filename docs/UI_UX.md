# UI/UX Requirements

## Visitor experience

### Locked screen

- Minimal, elegant design.
- Gallery title.
- PIN input.
- Unlock button.
- Generic error state.
- Do not reveal whether a partial PIN is correct.

### Gallery

- Responsive masonry/grid or justified grid.
- Lazy-loaded thumbnails.
- Full-screen viewer/lightbox.
- Previous/next controls.
- Close control.
- Smooth but restrained animations.
- No unnecessary UI clutter.

### Mobile

Optimize primarily for phone screens.

- Large touch targets.
- Avoid hover-only interactions.
- Prevent accidental navigation while viewing images.
- Respect safe areas/notches.

### Admin

Functional and clean rather than decorative.

- Upload dropzone/file picker.
- Preview queue.
- Progress.
- Delete controls.
- Confirmation dialog.
- Clear success/error feedback.

## Accessibility

- Semantic HTML.
- Labels for controls.
- Visible focus states.
- Keyboard-accessible lightbox.
- Meaningful alt text where available.
- Respect reduced-motion preferences.
